# 不拆机测试清单（ZV-E10 救援，2026-11-26）

> 目标：在不拆机、不送修、不买件的前提下，穷尽所有可能拿到"写入一次"或"让相机进可通信模式"的办法。
> 每条都标：怎么做、看什么、什么结果意味着什么。

---

## 观测工具（每项测试都用这三个判据）

1. **指示灯**：机身侧面小横条窗。正常砖态 = 约 2.66 秒循环闪一次。
2. **屏幕**：有没有任何亮光/画面。
3. **USB 身份**（相机接电脑时）：
   - `054C:0994` = 充电/关机模式（当前）
   - `054C:0D95` = USB 大容量存储（说明用户态起来了）
   - `054C:0336` = **服务模式（★ 这就是我们要的）**
   - `18D1:4EE0` = fastboot（说明 BootROM 注入成功）

Windows 下一条命令就能看：
```powershell
Get-PnpDevice -PresentOnly | Where-Object {$_.InstanceId -match 'VID_054C|VID_18D1'} |
  Select-Object Status,Class,FriendlyName,InstanceId
```

## A 组：软件探测（无需改硬件）

### A1. dump 0994 HID 描述符并试写 output report
- **状态**：进行中，`hid_dump.ps1` 打开设备成功但 `DeviceIoControl` 返回 `INVALID_FUNCTION`，需改路径/权限或换 WinUSB
- **若发现**：有 output report 或 vendor-specific 接口 → 试发命令，看是否有任何反应
- **意义**：这是相机当前唯一"活着且对着我们"的接口

### A2. 相机 OFF + 接电脑，长时间观察（≥5 分钟）
- **做法**：相机开关 OFF，接电脑，不做任何操作
- **看**：USB 身份是否曾经变化过（用上面的命令每 2 秒轮询一次，记录 5 分钟）
- **意义**：确认 OFF 态是稳定的 0994，还是会周期性掉线（后者说明 SoC 在循环）

## B 组：上电按键组合（改变 Loader 启动路径）

每组做法统一：
1. 相机开关 OFF（或拔电池）
2. **按住指定键**
3. 装电池 / 打开开关（保持按住 3 秒）
4. 观察三个判据

| # | 组合 | 备注 |
|---|---|---|
| B1 | 按住 **MENU** + 开机 | 部分 Sony 机进服务/恢复 |
| B2 | 按住 **回放键**（屏幕左下三角）+ 开机 | 回放/恢复模式 |
| B3 | **半按快门** + 上电池 | 强制 bootloader 一说 |
| B4 | 按住 **MOVIE** 键 + 开机 | |
| B5 | 按住 **Fn** + 开机 | |
| B6 | 按住 **删除键（C2）** + 开机 | |
| B7 | 同时按住 **MENU + 回放** + 开机 | |
| B8 | 按住 **快门 + 回放** + 开机 | |

**判据**：USB 身份变成 `0D95`/`0336`，或屏幕亮，或指示灯节奏明显改变 → 立刻停下并报告。

## C 组：插头方向与 CC 配置（改接线，不拆机）

| # | 做法 | 依据 |
|---|---|---|
| C1 | **把 24pin 板反插 180°**，重跑一次注入 | 反插会把数据落到相机 B 面（B6/B7），CC 落到 CC2 |
| C2 | **上排 `B5` 用短线接 `A5`**（两 CC 共用一个 5.1k），重跑注入 | 上游接线图逐字如此；上游自述"数据线受 CC 控制的板级开关" |
| C3 | **数据/复位改接上排 `D−`/`D+`（B7/B6）**，重跑注入 | 上游备注："A6/A7 不行的话，尝试 B6/B7" |
| C4 | **CC 完全不接**（只 GND + D− + VBUS） | 已试过一次（RX+GND），这次带 VBUS |

## D 组：注入时序变体（纯软件，改参数即可）

| # | 参数 | 现状 → 要试 |
|---|---|---|
| D1 | **复位后等待** | 600 ms → **100 ms**（上游 `--reset-delay 0.1`） ← **最可疑** |
| D2 | 复位脉冲宽度 | 10 µs → **100 ms 低电平后释放** |
| D3 | 复位策略 | 有复位 → **完全无复位**（纯冷启动，已试过 payload 版，未试过垃圾波版） |
| D4 | 记录间隔 | 已改 14.4 ms（上游值） |
| D5 | 前导载波时长 | 500 ms → 0 ms（复位前不预加载波） |

---

## E 组：垃圾波参数变体（只为了问 ROM"你在听吗"）

| # | 做法 | 依据 |
|---|---|---|
| E1 | 233 µs 方波（已试，无 13 闪） | `uart_boot_probe` 原件 |
| E2 | **改频率**：10 µs / 50 µs / 1 ms 半周期各试一遍 | 若 ROM 的波特率不是 2145，13 闪不会出现 |
| E3 | **只在冷启动瞬间发 3 秒**，其余时间不驱动 | ROM 的采样窗口可能只有几十 ms |
| E4 | 先发 1 秒**常低**，再发方波 | 有些 ROM 要求先看到 break 条件 |

---

## F 组：电源与状态

| # | 做法 | 依据 |
|---|---|---|
| F1 | **满电电池**（充电 2 小时后）再试 | 三周循环重启，电池可能欠压 |
| F2 | **拔掉电池，只靠 VBUS 5V** 试一次 | 排除电池管理干扰 |
| F3 | 相机 **ON 状态下插拔 USB-C**（不是 OFF） | 我们多数测试是 OFF 起的 |

---

## 优先级（按期望值/成本）

1. **D1**（一个参数，2 分钟）——上游就是 100 ms，我们用了 600 ms
2. **C2**（一根线）——上游接线图明确有，我们漏了
3. **B 组**（无需改线，几分钟）
4. **E2/E3**（问 ROM 在不在听，换个问法）
5. **C1/C3**（反插/换面）
6. **A1/A2**（软件探测）
7. 其余
