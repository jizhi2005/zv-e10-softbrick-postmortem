# 给维修圈的中文帖（可直接复制）

> 用途：发到数码之家、色影无忌、摄影论坛，或私信淘宝/闲鱼的相机维修店家。
> 核心只有一句：**求 ZV-E10（主板料号 SY-1121）的点位图，或 BOOT_SERIAL_IN 测试点位置。**

---

## 版本 A：论坛发帖（数码之家 / 色影无忌）

**标题：**
```
求 ZV-E10 点位图（主板 SY-1121）—— 想找 BOOT_SERIAL_IN 的测试点，有偿
```

**正文：**

```
各位老师好。

我有一台 ZV-E10 一代，因为自己改机时写坏了 /etc/ld.so.preload，开机不了。

已经确认是纯软件问题，不是硬件损坏：
  · 相机每 2.66 秒一轮重启，灯会闪
  · 接电脑能枚举出 USB 设备（054C:0994，"USB Charger"）
  · 内核、USB、存储分区全部正常，只是系统起不来

修复本身极其简单——让那个文件变空就行，一个字节的事。问题是**没有写入通道**：
  · 没有 Multi 口，只能用 USB-C
  · 试过从 USB-C 的 D−/D+ 打串口启动（上游公开资料说这条路可行），
    波形我用纳秒采样验证过是对的，但相机完全没反应
  · 试过 SD 卡升级（一代没有记忆卡版固件，实测无效）
  · 试过按键组合、USB 各种身份，都不行

我是从 a6400 官方维修手册（同一颗 CXD90045）里查到这些信息的：
  · BOOT_SERIAL_IN  在 SoC 的 BGA 球 G18 / L19
  · 启动模式选择     BOOT_EXT(N8) / BOOT_SIMPLE(P4) / BOOT MODE(AL24) / BOOT_NVM(AH23)
  · 复位             XRESET_REQ(L11)、XSYS_RST(A8)

所以想请教两件事：

  1. **有没有 ZV-E10 的点位图（主板料号 SY-1121）？**
     或者拆机照上，能不能看到 SoC 附近这几个测试点引到哪了。
  2. **索尼工厂做"基板制作"时，治具接触的是哪几个点？**

有偿，价格您开。如果只需要我把机器寄过去让您处理，也可以谈。

我自己整理的完整排查记录在这里（不影响您判断，附上只为说明我不是瞎试）：
https://github.com/jizhi2005/zv-e10-softbrick-postmortem

谢谢！
```

## 发帖注意

1. **不要一次发很多地方** —— 论坛对"到处贴一样的内容"很反感。先发**一个**最对口的地方（数码之家维修区），有人回了再考虑其他。
2. **"有偿"这三个字一定要留** —— 维修圈愿意帮陌生人，但更愿意帮"懂规矩"的人。点位图是他们的饭碗。
3. **别把英文和技术细节堆太多** —— 上面版本已经把必须保留的（G18/L19、BOOT_SERIAL_IN、SY-1121）控制在最少。
4. **被问到"你怎么肯定是软件问题"** 时，回答：**能枚举 USB 设备、每 2.66 秒规律重启**——这两条足够说明 SoC 是活的。
5. **如果有人愿意帮但需要详细信息**，把 GitHub 链接发给他（那里有全部证据，比他一条条问快）。
